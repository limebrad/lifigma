# Mini Figma

Мини-копия Figma на **React + TypeScript + Tailwind CSS v4** (Vite).

Живая версия: https://limebrad.github.io/lifigma/

## Архитектура

```
src/
├── types/       # Единый язык проекта: Shape, Tool, SelectMode, координаты
├── constants/   # Константы: инструменты и горячие клавиши (V / R / O)
├── utils/       # Чистая математика: переводы экран <-> мир, геометрия хит-тестов, помощники DOM
├── hooks/       # Логика без интерфейса: камера, фигуры, клавиши
└── components/  # Интерфейс: холст и панели
```

Правила, которые держат код в единстве:

- `types/` — единственное место, где описаны сущности; остальные файлы импортируют оттуда.
- `hooks/` не знают про DOM, `components/` не знают, как хранится состояние: всё передаётся пропсами.
- Состояние фигур пишется **только** через `commitShapes` в `useShapes`, иначе зеркало `shapesRef` разойдётся с отрисованным.

## Возможности

- сетка на фоне холста (мелкая, крупная + мировые оси, линии сетки совпадают с миром 0);
- панорамирование: **пробел + левая кнопка** или средняя кнопка;
- зум колесом **от 10% до 400%** с привязкой к точке под курсором (нормирован под тачпад);
- инструменты в левой панели: выбор, прямоугольник, эллипс;
- рисование фигуры перетаскиванием мыши, `Escape` отменяет рисование;
- **выделение**: клик, `Shift`+клик (добавить), `Ctrl/Cmd`+клик (переключить), `Ctrl/Cmd+A` (всё);
- **перетаскивание** мышью — вся выборка едет как единое целое;
- **удаление** выделенного: `Delete` / `Backspace`;
- **история**: `Ctrl/Cmd+Z`, повтор — `Ctrl/Cmd+Shift+Z` или `Ctrl/Cmd+Y`;
  частые правки одного свойства сливаются в один шаг;
- **панель свойств**: тип, координаты, размер, цвет заливки (пикер, hex/CSS-ввод, палитра пресетов);
- **панель слоёв**: список фигур сверху вниз, клик по слою выделяет фигуру на холсте.

Полный разбор качества кода и список исправленных дефектов — в [AUDIT.md](AUDIT.md).

## Доступность

Холст помечен `role="application"` с подписью, смена выделения озвучивается
скринридером, инструменты — `radiogroup`, слои — `listbox` с множественным
выбором. Полноценного рисования с клавиатуры пока нет (см. AUDIT.md, P2).

## Команды

```bash
npm install
npm run dev          # запуск
npm run build        # проверка типов + сборка
npm run typecheck    # только проверка типов
npm run lint         # eslint
npm run preview      # локальный просмотр собранного dist/
```

Требуется Node **>= 20.19** (или 22 LTS) — этого требует Vite 8.
В CI те же проверки выполняются перед публикацией: линт, затем сборка.

## Публикация

Каждый пуш в `main` запускает workflow «Deploy to GitHub Pages»
(`.github/workflows/deploy.yml`): `npm ci` → `npm run lint` → `npm run build` →
выкладка в GitHub Pages. Базовый путь сборки — `/lifigma/`, он задан в
`vite.config.ts` и соответствует адресу сайта.
