# Mini Figma

Мини-копия Figma на **React + TypeScript + Tailwind CSS v4** (Vite).

## Архитектура

```
src/
├── types/       # Единый язык проекта: Shape, Tool, координаты
├── constants/   # Константы: инструменты и горячие клавиши (V / R / O)
├── utils/       # Чистая математика: переводы экран <-> мир с учётом зума и панорамы
├── hooks/       # Логика без интерфейса: камера, фигуры, клавиши
└── components/  # Интерфейс: холст и панели
```

## Текущий шаг (этап 2)

Работает:
- сетка на фоне холста (мелкая, крупная + мировые оси);
- панорамирование: **пробел + левая кнопка** или средняя кнопка;
- зум колесом **от 10% до 400%** с привязкой к точке под курсором;
- инструменты в левой панели переключаются;
- **выделение кликом** — рамка и маркеры вокруг фигуры;
- **перетаскивание фигуры** мышью (выделенная фигура едет за курсором);
- **панель слоёв** — список всех фигур, клик по слою выделяет фигуру на холсте.

Заготовки готовы для следующих шагов:
- `useHotkeys.ts` — горячие клавиши V / R / O;
- `PropertiesPanel.tsx` — изменение размера и положения с клавиатуры.
